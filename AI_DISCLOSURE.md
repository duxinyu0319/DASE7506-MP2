# AI assistance and reused work
Substantive ChatGPT/Codex assistance was used for feature engineering, code implementation, evaluation execution, validation error analysis and report drafting. 

The original data, frozen representations, official loading/checking utilities, numeric parser, runner and scorer were supplied by the coursework. Official code/data are reused unchanged where stated. NumPy and SciPy provide numerical operations; Matplotlib formats the report. No external training dataset, additional pretrained weights or LLM generation/API call is used in inference. Qwen-generated candidate texts and embeddings are supplied inputs, not downloaded model weights.
